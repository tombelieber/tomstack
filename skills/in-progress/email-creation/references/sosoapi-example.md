# Approved SosoAPI design reference

The source bundle at [assets/sosoapi-example](../assets/sosoapi-example/) captures
the user-approved email design direction from 24 October 2026:

- Twelve essential examples, with optional marketing and future-feature emails
  excluded from the catalog.
- Cream surfaces, dark green text, mint CTAs, and the actual SosoAPI mascot logo
  beside the product name.
- Clear, friendly written language. Hong Kong and Taiwan Traditional Chinese
  have separate wording; Simplified Chinese is also separate.
- Eighteen language options matching the website configuration inspected for
  that task, with Arabic/Hebrew RTL support.
- One main action per example, synthetic recipients/workspaces, and unresolved
  account, billing, expiry, and count values represented by placeholders.

Public product reference: [SosoAPI](https://sosoapi.ai/). The logo is an existing
product asset supplied by the user's project; it was not recreated or generated.
Use it for this SosoAPI example and replace it for other products. Inclusion of
the brand reference does not represent endorsement of unrelated products.

## Scope and provenance

The reusable workflow is derived from the user's email design and revision
requests. Competitor screenshots informed the general hierarchy; they are not
bundled. No private repository history, production records, customer addresses,
provider credentials, local machine paths, or competitor images are required
to render these examples.

Jamie, Alex, Studio, `@studio.example`, and the displayed sign-in code are
synthetic fixtures. Security and lifecycle wording is sample copy inherited from
the approved designs, not a guarantee that a deployed SosoAPI release implements
every described behavior. Verify current trigger and policy contracts before
using any example for actual delivery. In particular, recheck receipts, grace
periods, renewal/cancellation, deletion/restoration, and publishing recovery.

The translated copy is a design draft. Schema and placeholder checks do not
constitute an independent native-language review, and browser rendering does
not prove compatibility with Gmail, Outlook, Apple Mail, or an email provider.

## Adapt the source, not the assumptions

Keep this bundle as the reference. For a new product, work on a copy in its task
directory and replace the logo, name, palette, contact/website text, language
registry, scenarios, fixtures, and product claims. Do not carry over SosoAPI's
exact scope or colors unless the user requests them.
